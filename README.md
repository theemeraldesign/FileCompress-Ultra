# FileCompress Ultra 2.0

A privacy-first client-side file compression and conversion studio.

## Included
- Responsive redesign
- Drag & drop
- Image compression and WebP conversion
- PDF optimization/re-save
- ZIP packaging
- Progress feedback
- Compression statistics
- Local browser processing
- No backend required

## Run
Open `index.html` in a modern browser or deploy the folder as a static site.

## Privacy
Files are processed in the browser and are not uploaded by the application.
